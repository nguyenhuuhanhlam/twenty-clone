# Mẫu UI CRM

Prototype HTML/CSS/JS thuần, mô phỏng một phần UI Twenty CRM:

- Sidebar trái: Nhà, Liên hệ, Cài đặt, user.
- Bảng danh sách liên hệ.
- Click một dòng để mở panel chi tiết dạng split.
- Có thể resize panel, đóng bằng nút X hoặc Escape.

Mở trực tiếp `index.html` trong trình duyệt để xem.
